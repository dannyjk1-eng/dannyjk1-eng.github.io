Put this menu, or an app, on your home screen

Each one installs on its own, so you can have three separate icons:

  1. This menu (Technician Tools): on Android (Chrome) tap ⋮, then Install app. On iPhone (Safari) tap Share, then Add to Home Screen.
  2. Flange ID and Pipe Reference: open the app first, then install it from there the same way.
